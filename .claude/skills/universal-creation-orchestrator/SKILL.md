# Universal Creation Orchestrator — portable project adapter

Canonical source (pinned review): https://github.com/vmoulakakis/Myagenticteam/blob/8154a27e6b904791343dfde0693f446c2f7fda40/skills/universal-creation-orchestrator/SKILL.md
Scope: this repository only. This self-contained adapter makes skill discovery possible for local coding agents; it does NOT grant access to the private central repository or authorize a global deployment.

1. Determine requested DELIVERABLE and mode: DISCOVER, ARCHITECT, BUILD, IMPROVE, AUDIT, RELEASE, or RECOVER. Do not silently turn a PRD/design request into a code change.
2. Inspect this repo's AGENTS.md, architecture, package/runtime, local skills, security, DESIGN.md, tests and currently deployed evidence; preserve every existing product contract.
3. Choose only relevant, available specialist skills. Substantive software/cloud follows ADLC and independent review; AI agents follow bounded agent-runtime; UI follows project design, accessibility, browser verification. For ERP/SAP guard the schema and read-only permissions.
4. Use the smallest native stack and actual deliverable. For UI: content and flow first; existing components; CSS -> Motion -> GSAP -> WebGL only when justified, reviewed and accessible. Do not auto-install demo-video tools or disable readable page scrolling globally.
5. Maintain a creation contract: audience/problem, exact output, must-change/must-preserve, data provenance, chosen skills/tools, measurable acceptance, risk/approvals, evidence.
6. Work in a reviewable scoped diff. Run relevant lint/type/build/tests and real user-flow/browser or artifact QA. Never claim screenshots, deployed health, conversions, prices, test passes or a linked private skill was actually loaded unless verified.
7. A tool, plugin or skill being linked is NOT installed. If central Myagenticteam access is available, read its current canonical skill and domain references; otherwise apply these local minimum rules and report the missing upstream.
8. Never access secrets unnecessarily, exfiltrate data, make unauthorized SAP production writes, send third-party messages, delete, spend or deploy irreversible changes without exact approval.

Report real artifacts, checks that were RUN, untouched scope, risk and status: PLANNED / CREATED / TESTED LOCAL / READY FOR REVIEW / PRODUCTION VERIFIED / BLOCKED.
